🏦 Bank Loan Report & Analytics Dashboard

📌 Project Overview

This project focuses on analyzing bank loan data to understand loan applications, funded amounts, payments received, loan performance, and borrower characteristics.

The project includes SQL-based data analysis and interactive dashboards designed to present key loan metrics and trends in an easy-to-understand visual format.

The analysis covers data for 2021, with particular focus on December 2021 (MTD) and November 2021 (PMTD) comparisons.

⸻

🎯 Project Objectives

The main objectives of this project are:

* Analyze overall loan application volume
* Track total funded loan amounts
* Analyze total payments received
* Compare MTD and PMTD performance
* Analyze average interest rate and DTI
* Identify good and bad loan performance
* Analyze loan status
* Understand loan trends by month
* Analyze loan distribution by state
* Compare loan terms
* Analyze employee length
* Analyze loan purposes
* Analyze home ownership categories
* Present findings through interactive dashboards

📊 Key KPIs

The project analyzes the following major Key Performance Indicators (KPIs):

Loan Applications

* Total Loan Applications
* MTD Loan Applications
* PMTD Loan Applications

Funded Amount

* Total Funded Amount
* MTD Funded Amount
* PMTD Funded Amount

Amount Received

* Total Amount Received
* MTD Amount Received
* PMTD Amount Received

Loan Metrics

* Average Interest Rate
* Average DTI

Good Loans

* Good Loan Percentage
* Good Loan Applications
* Good Loan Funded Amount
* Good Loan Amount Received

Good loans are identified as loans with a status of Fully Paid or Current.

Bad Loans

* Bad Loan Percentage
* Bad Loan Applications
* Bad Loan Funded Amount
* Bad Loan Amount Received

Bad loans are identified as loans with a status of Charged Off.

🔍 SQL Analysis

SQL queries were created to calculate the project’s major KPIs and analyze loan performance.

The analysis includes:

* Aggregate functions such as COUNT(), SUM(), and AVG()
* Conditional calculations using CASE
* Date-based filtering using MONTH() and YEAR()
* Grouping using GROUP BY
* Sorting using ORDER BY

The SQL analysis also examines loan status, monthly trends, states, loan terms, employee length, loan purpose, and home ownership.
